# Aidan — VEX V5RC Coaching Website

Ready for GitHub Pages. Upload **index.html** and the **images** folder to the root of the `aidan-coaching` repository.

To publish: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

The photo gallery contains seven supplied competition, robot, team, and awards photos. To change a photo, replace the corresponding file in `images/` or edit its path in `index.html`.

Before sharing widely, replace the generic Discord button URL with your direct contact link.
